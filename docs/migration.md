# File Server & Client 2.x Migration Guide

## File Server

### Before you start

We assume that you have installed File Server 1.x.

:::note
SSL is enabled on all interfaces by default and cannot be disabled anymore
:::

### Upgrade to File Server 2.x

#### Upgrade Java

Install the latest JRE or JDK 17.

#### Shutdown File Server 1.x

Shutdown your current File Server application.

#### Upgrade EbMS Admin

Replace the file-server-1.x.jar by the latest file-server-2.x.jar and start the File Server application.
